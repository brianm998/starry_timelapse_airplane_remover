# s588: Icon Composer app icon for the macOS gui

Summary: The macOS gui now uses an Icon Composer `StarIcon.icon` (a full-bleed layer from BR-1 written by `art/export.py`) so macOS 26 shows the icon filling its rounded square, with Xcode generating the legacy icns for older macOS.

`gui/star/StarIcon.icon` replaces `AppIcon.appiconset` (actool builds the pre-26 `StarIcon.icns` from the bundle, so the
catalogue icon was unused). star-desktop keeps its icns: jpackage cannot take a `.icon`.
