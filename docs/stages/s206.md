# s206: Swift package compiler warnings

Summary: Cleared the compiler warnings from star's own Swift sources and tests (redundant await/try, unused results, unnecessary nonisolated(unsafe), missing @retroactive, GPU merge Sendable captures, Windows CRT nags, unhandled PROBLEMS file) with no behaviour change.

Fixed per the ticket's list; toolchain-specific ones (Linux/Windows await warnings, MSVC deprecations) are checked by CI. The KeypointLimiter tests now assert the acquire result (true: a parked waiter is granted a slot; a cancelled waiter is granted one too, as the implementation documents).

StarCpp changes trigger `test-StarCpp-wgpu`, whose device tests all skip on a machine without wgpu-native. `WGPUAvailabilityTests` (new) holds WGPUOps_C.h's availability contract instead — no backend or no `STAR_WGPU` opt-in means every entry point says "not available" and nothing is registered — and touches no GPU driver, so it runs everywhere.
