  140 of 368). Tiles are matted from black, not from a checkerboard, so the near-white fringe check now covers only the
  checker-cleaned cutouts it was written for; tiles keep their transparent-corner check. Every checked slot was measured
  with the test's own rule before the change (largest: art_waiting 19%, art_horizon_auto 15%).
