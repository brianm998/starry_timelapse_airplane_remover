## test-pipeline ran out of time

This change touches `.mason/` and `scripts/`, so the impact map selects `test-pipeline`. It ran
out of its 2 h `test_timeout_s` twice, at load 60-140 on 18 cores. Its tests spawn git thousands
of times. Each `/usr/bin/git` call goes through the xcrun shim: median 3.2 s against 1.1 s for the
real binary at that load. `pipeline/tests/conftest.py` now puts a `git` symlink to `xcrun --find git`
first on PATH for the session. It also sets `GIT_EXEC_PATH` and `GIT_TEMPLATE_DIR`, because a
symlinked Apple git otherwise falls back to a compiled-in `/Applications/Xcode.app` prefix.
Off macOS, or where git is not the shim, it does nothing.
