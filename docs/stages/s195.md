# s195: the import robot on the import sheets and loading ring (ticket #199)

Summary: Shows art_import (the import robot) at 96 pt beside the titles of the Import Video and Open Image Sequence sheets and centred in the loading ring (60% of its inner diameter, at most 120 pt), in both clients; the small spinner gets none.

- `loadingRingArtSize` is the shared rule in each client; `ScaledArtImage` draws a slot at a given height (the generated `ArtImage` only draws at display size).
- 96 is the robot's height; the width follows its 99:120 aspect.
- No strings, ids or test tags change.
