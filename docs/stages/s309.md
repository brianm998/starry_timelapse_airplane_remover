# s309: Installer and README art

Summary: README opens with the BR-7c hero JPEG (270 KB) and the desktop DMG gets BR-7a as its background with the app and Applications link in the left and right thirds; the Windows side panel is left out because its WiX override cannot be verified without Windows.

- `art/export.py` generates `docs/readme-hero.jpg`, `star-desktop/packaging/dmg/Star-background.png` and `Star-dmg-setup.scpt`; `--check` covers them.
- `build.gradle.kts` sets `jpackageResources` on the DMG package tasks.
- The DMG layout script placeholders (`DEPLOY_ACTUAL_VOLUME_NAME`, `DEPLOY_APPLICATION_NAME`) are jpackage's; they and the layout are unverified until the CI macos-signed job builds the DMG (not run on this Mac: it drives Finder).
- Windows panel (BR-7b): left out, see decision 0303.
