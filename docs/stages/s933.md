# s933 — output JPEG quality slider in both clients

Summary: Both clients' processing settings get an output JPEG quality slider that starts at the input's quality; the override is saved as `Config.outputJPEGQuality` and drives the quality the output frames are written at.

Task #847. Decision: docs/decisions/0926-output-jpeg-quality-override.md. Exit: scripts/exit/s933.sh.

`nil` = same as the input (`ImageAccessor` resolves it from the sequence); 1…100 overrides. The proto carries it as
`output_jpeg_quality` (0 = same as input) and the daemon tells the desktop client the input's quality in
`SessionInfo.source_jpeg_quality` (0 = not a JPEG sequence). Recorded in the output stage's artifact inputs, so a
change rewrites the outputs and keeps the alignment.
