# s889: the gui forgets deleted images

Summary: `ImageAccessor.imageDeletedClosure` fires for every image file `deleteImage` removes, and the macOS gui uses it to drop that type from the frame's `existingImages`, forget the loader's cached picture, and fall back to `.original` when the view mode lost its images.

Task #838. Decision: docs/decisions/0882-gui-forgets-deleted-images.md.
The desktop needs no change: stard computes `availableModes` from disk on each FrameInfo.

No exit script (see s828 on why). To verify by hand: `cd StarCore && STAR_USE_GPU_FOR_MERGE=0 swift test --filter ImageAccessorDeletedClosureTests`, and the gui's `-only-testing:starTests/ImageDeletionTests`.
