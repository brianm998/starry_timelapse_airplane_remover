Summary: The wgpu aligned-merge "matches Metal" test now compares with the CPU at the CPU bound when STAR_USE_GPU_FOR_MERGE forces the CPU merge, instead of holding a CPU result to the Metal bound, so it runs and passes on this Mac (decision 0335).
