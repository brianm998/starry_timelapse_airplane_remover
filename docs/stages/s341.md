# s341: the wgpu "matches Metal" tests compare with the CPU when STAR_USE_GPU_FOR_MERGE=0

Summary: The wgpu aligned-merge and warp "matches Metal" tests now compare with the CPU at the CPU bound when STAR_USE_GPU_FOR_MERGE forces the CPU merge, instead of holding a CPU result to the Metal bound, so they run and pass on this Mac (decision 0335).
