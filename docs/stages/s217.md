# s217: Change Mode picture tiles

Summary: the Change Mode dialog's clean choices show 40 pt tiles in both clients (Automatic, Selective, and one shared tile for Dirty), via `HighLevelCleanMethod.changeModeArt` in the gui and an optional `leading` slot on `VerticalStarPicker` in the desktop client.

`build-gui` could not pass on this machine: Xcode's own prefs (`IDEBuildLocationStyle=Custom`,
`IDECustomDerivedDataLocation=DerivedData`) beat `-derivedDataPath`, so the app landed in
`gui/DerivedData`, and the signing check looked for `star.app` on a case-sensitive volume where the
product is `Star.app`. `.mason/scripts/xcodebuild-signed.sh` now passes `-IDEBuildLocationStyle=Unique`
and `check-gui-signing.sh` defaults to `Star.app`.
