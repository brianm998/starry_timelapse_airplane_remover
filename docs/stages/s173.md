# s173: the first art set (ticket #192)

Summary: Adds `art/` (37 sha256-checked masters, `slots.json` with 32 slots, `export.py`) that cleans and sizes the first 41 generated images into gui imagesets and desktop `resources/art/` files, with a generated `StarArt` loader and accessibility-hidden `ArtImage` in each client.

- Masters keep what was received apart from a downscale (see `art/import_masters.py`). Cleaning happens only at export time.
- Five checkerboard pictures and eight black-cornered tiles are matted by flood fill from the border; real-alpha cutouts are used as they are; scenes are cropped and written as JPEG.
- `WL-3.png` is the SU-3b picture and is stored as `SU-3b`; TL-7, IM-2a, IM-2b are left out.
- Tests: `StarArtTest` (desktop), `testEveryStarArtSlotLoads` (gui `SharedConstantsTests`).
- No strings are added, so no catalogue change.
