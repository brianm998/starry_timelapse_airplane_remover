# s311: Welcome art

Summary: The Welcome screen shows the wordmark, greeter, night-sky still and a tile on each button, and the Information dialog opens with the robot-and-dog banner, in both clients.

Both `InitialView`s and both Information dialogs use `StarArt`. A shared tile mapping (`OpenKind.tileArt` / `tileArt(kind)`) feeds the buttons and the tests; `WelcomeArt` holds the greeter rule and banner band in each client. No strings added. See docs/decisions/0305-welcome-art.md.
