Summary: Opening a sequence no longer logs the per-frame "does not exist", "no filename for type blobs" and "failed to load outliers (file is missing)" lines, and a config change logs the KeypointLimiter, MemoryMonitor and KeypointCache lines only when a value in them changed.

Test: `OpenLogNoiseTests`. "Not loading twice" is left to task A5. No catalogue keys change.
