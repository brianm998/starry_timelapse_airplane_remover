# s879: lossless intermediates for JPEG sequences

Summary: Every full-size intermediate (aligned and earth-aligned merges, subtraction, horizon masks, validation and remove masks, per-frame painted reference) is written as `.tif` whatever the source format, with legacy `.jpg` painted files still read and an `intermediateFormatVersion` input that rebuilds an old JPEG-cache sequence once.

`FrameViewMode.isLosslessIntermediate` selects the types; `ImageAccessor.dirAndNameForImage` renames them at original size. Readers fall back to the old source-extension file for `.horizon`, `.mergedHorizon` and `.userHorizon` only; a TIFF write or a delete removes the old copy. Previews, thumbnails, `.original` and the output types are unchanged. Tests: `LosslessIntermediateTests`, a case in `ArtifactInvalidationTests`. No catalogue keys change; the clients share StarCore so neither needs a twin edit.

No exit script (see s828 on why). The `a7sii_10` folder-size before/after measurement was not run here.
