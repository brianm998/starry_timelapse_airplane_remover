# s222: GUI suites sign with the team's Apple Development identity

Summary: `build-gui` and `test-gui` now run xcodebuild through `.mason/scripts/xcodebuild-signed.sh`, which signs with "Apple Development" for team G3L75S65V9 (ad hoc if `STAR_TEST_SIGN_IDENTITY=-`), so macOS privacy approvals survive rebuilds.

Manual signing was chosen, not `-allowProvisioningUpdates`: the latter talks to the Apple account and can raise an Xcode dialog, which an unattended run cannot answer. Manual signing uses only the login keychain identity, and needs no profile for a macOS Debug app without restricted entitlements. Not verified by a build in this stage (no GUI build was run); `scripts/exit/s222.sh` checks a built app. GitHub CI is unchanged.
