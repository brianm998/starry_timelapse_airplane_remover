# s825: JPEG vs 16-bit TIFF parity measurement

Summary: `gherkin/compare-formats.py` compares star's removal on a7sii_10 (JPEG) against a7sii_10_16bit (TIFF) per object and per frame, and the removal-measure workflow publishes it and gates it on both OSes.

New `gherkin/compare-formats.py` (+ `gherkin/tests/test_compare_formats.py`), two `format_parity_*` thresholds (provisional until the first CI run is recorded in their `measured` note), CPU-tagged JPEG runs added to `measure-removal.sh` on macOS, workflow step on both jobs. The tests (`pipx run pytest -q gherkin/tests`) run in both removal-measure jobs before the measurement; they are not in pr-gate.yml, whose name the test step's name scan matches against pipeline tests.
