# s150 — star dialog style for the gui's plain sheets and popovers

Summary: The gui's plain sheets, popovers and the Work In Progress card now draw on the star dialog ground through one shared `starDialogStyle()` modifier instead of the system window background.

Task #160. gui-only: the desktop client already draws these as cards under `StarTheme`.

- `starDialogStyle()` (grey ground, white default foreground, dark colour scheme) lives in `gui/star/InfoDialogView.swift`; `KeypointDivisorStartupView` uses it in place of its own `sheetBackground` and `preferredColorScheme`.
- Applied to the outermost body of the fourteen listed views (the four `RenderVideoSheetView` states via its body `Group`) and to the Work In Progress card, which swaps `.regularMaterial` for it.
- Test: `gui/starTests/starTests.swift` `StarDialogStyleTests.testSheetsDrawOnTheStarDialogGround` hosts `ToolHelpView` and `AlignmentInfoContent` in a window forced to `.aqua` and compares a corner pixel with the same grey drawn under the dark scheme.
- No strings added or changed; `i18n/check.py` reports the catalogue complete.
