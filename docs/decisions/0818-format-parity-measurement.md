# 0818: format parity is measured, with provisional thresholds

A verdict is "removed" when an object's median stretch ratio is at most `removed_max`. Objects are matched by (frame stem, label id). macOS compares cpu-tagged runs on both sides; Linux compares the untagged CPU runs. The two thresholds are guesses (0.8, 0.15) because no CI run has measured the gap; they must be replaced from the first run's summary.
