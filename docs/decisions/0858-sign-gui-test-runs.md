# 0858: sign every gui test run

An unsigned test host is identified by cdhash, a new TCC identity every build, so the removable-volume Allow never sticks. Agents bypass the hook, so a PATH shim (shared by every caller) plus a hook rewrite route unsigned gui calls to `xcodebuild-signed.sh`. The wrapper sets `STAR_XCODEBUILD_SHIM_PASSED=1` to avoid looping.
